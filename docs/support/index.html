Support

支持与帮助

适用于 AI副业实验室 1.0。支持范围包括应用功能、内容访问、购买恢复和本地数据，不包括收入保证、客户撮合或代运营。

购买后未解锁

  1. 确认设备登录了购买时的 Apple 账户。
  2. 在应用“我的”中选择“恢复购买”。
  3. 保持网络可用并等待交易校验。
  4. 若仍有问题，请在 App Store 的“报告问题”页面核对交易。

管理或取消订阅

打开 iPhone“设置”→Apple 账户→“订阅”，选择 AI副业实验室。计费与退款资格由 Apple 管理。

清除本地数据

打开应用“我的”→“本地数据”→清除进度；卸载应用也会删除设备上的行动进度。

指南不构成财务、法律、税务或就业建议。项目结果受市场、能力、时间与执行影响，不能保证收入。

联系

请通过 App Store 产品页面的“App 支持”入口访问本页。为保护隐私，请勿发送银行卡号、Apple 账户密码或完整交易凭证。
